# skills

Opinionated personal agent skills, for my daily work.

```bash
npx skills add arikchakma/skills
```

| Skill | What it does |
| --- | --- |
| `/commit` | Stage and commit changes as conventional commits |
| `/create-branch` | Branch off a freshly-fetched default branch, conventionally named |
| `/pr` | Open a pull request with `gh`, filling the repo's PR template |
| `/discuss` | Talk through a problem with no code written until asked |
| `/comments` | Write comments that earn their place, delete the ones that do not |
| `/daily-news-brief` | Summarize Hacker News and GitHub Trending into one page |
| `/react-component` | Write React components to this codebase's conventions |

Type the slash command to run any of them. `/discuss` is slash-only; the rest the agent can also invoke on its own when the task calls for it.
